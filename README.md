# GasCalculator ⛽

Este projeto é uma **calculadora de gastos com combustível**, criada com HTML, CSS e JavaScript. A ferramenta permite ao usuário calcular o custo de uma viagem ou estimar a quantidade de combustível necessária, com base em informações como a distância percorrida, o preço do combustível e o consumo do veículo.

O desenvolvimento deste projeto foi uma oportunidade excelente para praticar e consolidar conceitos básicos de front-end, como:
* **Lógica de programação:** Implementando a fórmula de cálculo diretamente no JavaScript.
* **Manipulação de formulários:** Capturando os valores inseridos pelo usuário.
* **Atualização dinâmica da interface:** Exibindo o resultado do cálculo na tela.
